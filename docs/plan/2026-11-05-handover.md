## P2 — rebalancing + backtesting (done)
* `lib/core/rebalance.dart`: absolute drift bands (3% default; 200/175 bp
  glide-path preset), cash-flow rebalancing (contributions fill underweights,
  withdrawals drawn from overweights, no sells/buys in the wrong direction),
  sell-based fallback shown only as a simulated suggestion.
* `lib/core/forecast.dart`: classical simple exponential smoothing, grid-fit
  alpha, widening prediction band, rolling-origin track record (band hit rate,
  MAE vs naive). Labelled as a model everywhere it is shown.
* `lib/core/backtest.dart` + `sample_data.dart`: 20 years of **synthetic**
  seeded monthly returns; never / annual / threshold rebalancing compared.
* `lib/ui/insights_tab.dart`: Insights tab (rebalance, backtest chart,
  forecast with confidence band and track record).
* Evidence: `test/core/rebalance_test.dart` (17 tests), Insights widget test.
  Full suite 38/38, analyze clean.

Known limits: backtest ignores costs/tax; forecast is SES on annual returns
(close to a mean estimate) and is a stub for later models.

## P4 — AI / agents (done)
* Off by default twice: `agents.enabled` (Agents tab needs a tap to turn on)
  and `ai.enabled` (Settings -> AI narration). No bundled model, no default
  endpoint, no key in code.
* `lib/ai/llm_client.dart`: local OpenAI-compatible, cloud OpenAI-compatible
  and Anthropic Messages; https enforced for cloud; HTTP errors never echo
  the response body. `ai_store.dart`: non-secret settings in the DB; API key
  only in the OS keychain (`samridhi_ai_key_v1`).
* `lib/ai/digest.dart`: the only data an agent sees: 2-s.f. totals, 5%-rounded
  weights, goals as "Goal N"; no names/ids. Tested.
* `lib/agents/`: deterministic agents (risk, portfolio, forecast, rebalancing,
  wrapper/tax-location), each suggestion carries a confidence/basis line;
  `Orchestrator` sequences them, isolates failures, has no side effects.
  `Narrator` (LLM) explains in prose only; output is displayed, never parsed
  into actions, and labelled AI-generated.
* "Accept" on a rebalance suggestion only writes a `SuggestionLog` row
  (schema v3) and says "Accepted - not executed". Tested that holdings are
  untouched. Market-data / risk-profile LLM agents from the plan are not
  separate LLM agents: risk/portfolio/rebalance are deterministic by design.
* Evidence: `test/agents/agents_test.dart` (19), widget tests for agents tab.
  Suite 72/72.

Not verified: a real call to an Ollama/cloud endpoint (tests use MockClient).
