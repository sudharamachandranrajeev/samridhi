## P2 — rebalancing + backtesting (done)
* `lib/core/rebalance.dart`: absolute drift bands (3% default; 200/175 bp
  glide-path preset), cash-flow rebalancing (contributions fill underweights,
  withdrawals drawn from overweights, no sells/buys in the wrong direction),
  sell-based fallback shown only as a simulated suggestion.
* `lib/core/forecast.dart`: classical simple exponential smoothing, grid-fit
  alpha, widening prediction band, rolling-origin track record (band hit rate,
  MAE vs naive). Labelled as a model everywhere it is shown.
* `lib/core/backtest.dart` + `sample_data.dart`: 20 years of **synthetic**
  seeded monthly returns; never / annual / threshold rebalancing compared.
* `lib/ui/insights_tab.dart`: Insights tab (rebalance, backtest chart,
  forecast with confidence band and track record).
* Evidence: `test/core/rebalance_test.dart` (17 tests), Insights widget test.
  Full suite 38/38, analyze clean.

Known limits: backtest ignores costs/tax; forecast is SES on annual returns
(close to a mean estimate) and is a stub for later models.

## P4 — AI / agents (done)
* Off by default twice: `agents.enabled` (Agents tab needs a tap to turn on)
  and `ai.enabled` (Settings -> AI narration). No bundled model, no default
  endpoint, no key in code.
* `lib/ai/llm_client.dart`: local OpenAI-compatible, cloud OpenAI-compatible
  and Anthropic Messages; https enforced for cloud; HTTP errors never echo
  the response body. `ai_store.dart`: non-secret settings in the DB; API key
  only in the OS keychain (`samridhi_ai_key_v1`).
* `lib/ai/digest.dart`: the only data an agent sees: 2-s.f. totals, 5%-rounded
  weights, goals as "Goal N"; no names/ids. Tested.
* `lib/agents/`: deterministic agents (risk, portfolio, forecast, rebalancing,
  wrapper/tax-location), each suggestion carries a confidence/basis line;
  `Orchestrator` sequences them, isolates failures, has no side effects.
  `Narrator` (LLM) explains in prose only; output is displayed, never parsed
  into actions, and labelled AI-generated.
* "Accept" on a rebalance suggestion only writes a `SuggestionLog` row
  (schema v3) and says "Accepted - not executed". Tested that holdings are
  untouched. Market-data / risk-profile LLM agents from the plan are not
  separate LLM agents: risk/portfolio/rebalance are deterministic by design.
* Evidence: `test/agents/agents_test.dart` (19), widget tests for agents tab.
  Suite 72/72.

Not verified: a real call to an Ollama/cloud endpoint (tests use MockClient).

## P5 - platform polish (done; platform behaviours partly unverified)
* **App lock** (`lib/security/pin_lock.dart`, `lock_controller.dart`,
  `ui/lock_gate.dart`): salted Argon2id PIN hash in the OS keychain, 5 free
  tries then doubling lockout (persisted), constant-time compare, relock after
  30 s in background, optional biometrics via `local_auth` (falls back to PIN
  on any error). A UI gate, not encryption - stated in the UI.
* **Report a problem / request a feature** (`lib/support/issue_report.dart`,
  Settings -> Help): prefilled GitHub issue-form URL using the existing
  templates' field ids (a test checks the ids exist); user sees exactly what
  is included and submits in the browser themselves. `lib/app_info.dart`
  holds the version (a test keeps it equal to pubspec).
* **Updater with rollback** (`lib/update/`): GitHub Releases check (button
  only, no polling), downloads only from this repo's release URLs, verifies
  `SHA256SUMS.txt` (fails closed), size cap, zip-slip guard, stage -> atomic
  directory swap -> N-1 kept -> one-tap rollback, health marker with automatic
  rollback after 2 launches that never confirm. Installed copy hands over to
  the stored newer copy at startup (`launcher.dart`, `main.dart`).
  Android: opens the releases page (APK install is manual).
* **Sentinel** (`lib/security/sentinel.dart`, Windows only): speaks Sentinel's
  length-prefixed JSON hello over `\.\pipe\sentinel` in an isolate with a
  timeout; absent/restricted/unusable all degrade to a status line. Sentinel's
  protocol exposes no Defender/tamper signals yet, so the badge only says
  "running". Its pipe is admin-only by default, so an ordinary Samridhi will
  usually see "running (needs administrator)".
* **Security status card**: DB integrity (`PRAGMA integrity_check`), app lock
  state, Sentinel row (Windows).
* **Motion** (`lib/ui/motion.dart`): animated tab switch and allocation bars;
  zero duration under OS reduce-motion (tested).
* Evidence: pin_lock (7), issue_report (5), update (17), sentinel/db (5) unit
  tests, lock-gate and reduced-motion widget tests. Suite 108/108, analyze
  clean.

Not verified (no way to here): a real in-app update end to end (needs a
published release with SHA256SUMS.txt and a built bundle); Windows Hello /
fingerprint prompts; the Sentinel handshake against a live service; process
relaunch on Linux. Rollback across a DB schema change is NOT automatic: the UI
tells the user to export a backup before updating. Deferred from the plan:
screen-capture warning and root/jailbreak-ish detection on Android; the
`local_auth` Android manifest/activity changes land with P6.

## P6 - release pipeline, installers, Android

* Reviewed release.yml, Linux installer, Windows installer: Artha leftovers
  removed (header notes updated; Flutter pinned to 3.47.9 to match the
  project's Dart constraint).
* Database now lives in the app-support directory (`getApplicationSupportDirectory`;
  Linux `~/.local/share/dev.samridhi.samridhi`, Windows per-user `%APPDATA%`)
  instead of drift_flutter's default user-visible Documents folder, which
  matches what the installers/uninstallers tell users. Unreleased, so no
  migration.
* Android: INTERNET + USE_BIOMETRIC permissions in the main manifest (release
  builds lacked INTERNET), `FlutterFragmentActivity` for `local_auth`,
  https `<queries>` for url_launcher, `allowBackup=false` (no cloud backup of
  the encrypted DB), label "Samridhi". `usesCleartextTraffic` is on only so
  users can reach a LAN/local self-hosted server or local LLM over http; the
  app itself refuses http for cloud AI and non-local servers.
* Windows: `_SILENCE_EXPERIMENTAL_COROUTINE_DEPRECATION_WARNINGS` so
  `local_auth_windows` builds on current MSVC.
* Evidence: `workflow_dispatch` run 42023706194 - test, version, windows,
  android, linux all green (publish skipped by design). `bash -n` clean on
  install scripts. No tag created.
